Owned process-state freeze proof failures (written before implementation)

Scope: Windows 11 owned native targets only. No game, Steam, debugger, or patch integration.
The proof must retain PID, creation FILETIME, executable identity, OS and native DLL identity.

1. Missing native export: refuse before a state object or freeze exists.
2. Wrong PID or creation time: refuse before a native state operation.
3. Insufficient process/state access, invalid object, invalid state, reserved arguments,
   wrong target, or exited target: retain raw NTSTATUS. No success claim on refusal.
4. Existing ordinary, hidden, waiting, and churn workers run after suspend returns.
5. A future ordinary remote thread runs while the state object remains suspended.
6. A bypass-process-freeze thread continues. Record this limit explicitly.
   Stable ordinary counters do not prove an arbitrary process has all threads stopped.
7. Explicit resume fails or counters do not resume. Do not hide this with handle close.
8. Closing one duplicate thaws the process despite another state reference.
9. Closing the last state reference leaves ordinary workers frozen.
10. One independent state object resumes another object's suspension.
11. State resume discards a preexisting per-thread suspension.
12. Controller death drops the final state reference and workers see a partial marker.
    This is a publication hazard, not a passing transaction contract.
13. Candidate death protection fails: controller-only KILL_ON_JOB_CLOSE job and
    child-held state reference do not kill the frozen owned child before any worker
    sees the partial marker. Target exit must have a retained raw exit code.
14. The child-held state reference cannot be closed after explicit resume.
15. A fixture failure leaves a child or freeze handle behind. Each target belongs to
    a parent-only kill-on-close job. Close/terminate only an exact owned identity.
16. A receipt omits observations, raw statuses, identities, or artifact hashes.
17. A dedicated tight user-mode worker executes after suspend returns. It must
    perform no sleep, wait, or voluntary yield in its heartbeat loop.

Sampling is bounded evidence. Native API success plus stable counters does not
prove arbitrary kernel wait completion or production-safe all-thread admission.
