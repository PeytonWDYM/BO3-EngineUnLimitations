Owned enhanced-launcher failures, declared before implementation

1. Refuse the production CLI before creating a process when the executable hash differs.
2. Admit the actual combined production helper in a stopped owned child.
3. Refuse a damaged boot record before preparing any hook edits.
4. Refuse a modified mapped code byte, even when its disk file still matches.
   Also refuse a changed unwind record in the read-only helper metadata.
5. Preserve the parent's Steam variables and confirm the child's app identity.
6. Keep the production VM and migration POD records zero before patch publication.
7. Bind build inputs, actual helper bytes, child exit, and private evidence by hash.

These cases execute only an owned test process and the project's helper.
They do not execute BO3, Steam SDK APIs, or native game instructions.
