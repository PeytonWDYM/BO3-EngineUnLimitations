Optional enhanced launcher failures declared before implementation:
1. Missing optional bundle must be unavailable, never start a process.
2. Corrupt launcher, helper, or license must refuse before private extraction.
3. Unsupported game identity, open BO3, or absent Steam must refuse before extraction.
4. Unsafe manifest version, filenames, hash values, or extra payloads must refuse.
5. Existing extracted payload corruption, extra files, hard links, or directory redirects must refuse without overwriting.
6. Interrupted extraction must never publish a partial launcher/helper pair; a later attempt may safely publish a complete version.
7. Private tools must remain outside the selected installation, including redirected ancestors.
8. Successful owned stand-in handoff must use a complete verified pair, exact game argument, separate console, and tools working directory.
9. Launch handoff must preserve all game/settings bytes and the parent environment.
10. Ordinary builds without native payload remain usable; packaged optional resources must match the pinned public manifest.
11. A still-running enhanced launcher must block a second handoff before BO3 appears, including at the final admission check.
12. Missing bundle and unsupported game refusals must precede Steam admission, including on a machine without Steam.
