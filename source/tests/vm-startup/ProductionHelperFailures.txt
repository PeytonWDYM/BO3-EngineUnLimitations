Production helper failures, declared before implementation

Use the fixed owned native child. Do not launch BO3 or change its installation.

1. The release helper must load without a fixture mapping or environment variable.
2. It must restore temporary Detours imports before publishing its boot record.
3. The boot record must identify its ABI, loaded image and ready state.
4. All state and error bindings must remain zero until the paused parent binds them.
5. The parent must refuse a wrong boot ABI or missing readiness before target writes.
6. Real state exports, original thunks, error recovery and rollback must retain their existing contracts.
7. The release helper must contain no fixture exports, game dependencies or dynamic C++ initializers.
8. The artifact must record the exact helper imports, TLS, exports and source hashes.

The owned target does not establish BO3 startup timing, Steam context or multiplayer compatibility.
