Native VM error routing: focused failures before implementation

Use owned functions and owned executable memory only.
Do not call BO3 or AAE code.

1. A successful reader or writer must return normally without calling the engine error entry.
2. Each nonzero StateError must call the active error entry with ERR_DROP code 2.
3. The error prelude must preserve all four fixed argument registers and every caller stack argument.
4. TLS clearing may clobber volatile registers. The original error call must retain its arguments.
5. A native non-local error exit must leave the import context inactive.
6. A native error during slot decoding must clear TLS even when no StateError returns to the wrapper.
7. A later MinHook-style entry detour must retain the installed prelude through its saved trampoline.
8. That later callback must preserve its forwarding and suppression behavior.
9. The installed prelude must have valid Windows unwind metadata for its stack frame.
10. The recovered five-byte R9 home-store must execute once through the owned original trampoline.

Use the exact recovered instruction 4c894c2420 in the owned entry model.
Record argument receipts, error code, TLS state, chain order, non-local exits, and unwind results.
Owned coexistence does not establish actual AAE coexistence or stock game initialization.
