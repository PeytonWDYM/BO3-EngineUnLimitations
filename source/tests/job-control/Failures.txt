Failure matrix recorded before implementation

1. Wrong executable/helper/gate file or process PID/FILETIME/path: refuse before resume or admission. Keep exact frozen hashes and file locks.
2. Parent-only job assignment or sole membership fails: refuse suspended child; repeat membership inside freeze and after thaw.
3. Freeze/thaw returns any status except0: retain raw NTSTATUS, no gate release, end exact owned child.
4. GateReady/Waiting identity, generation, native callback thread, deadline, or debugger absence differs: refuse before release.
5. Thread inventory is not exactly original primary, hardware breakpoints exist, or full guarded runtime unwind/anchor is absent: same current refusal; no thread widening.
6. Any82 code guard,19 full stock count instructions, stock entry/immediate original, helper code/Boot/binding, or empty VM/migration field differs: refuse while frozen. Never call publication to repair it.
7. Read/protection-query fails or an observation RVA exceeds the pinned image: record address/size/phase/error. Required admission failure refuses; optional observation failure records a gap and never changes admission.
8. Any native edit, relay allocation, VirtualProtectEx, FlushInstructionCache, SetThreadContext, debugger attachment/events/detach, PSS, child LoaderThreads write, or hardware-register write occurs in the control publication path: fail owned proof/import/source review before game use.
9. Absolute30second startup budget expires: kill while frozen if necessary; do not lengthen the gate budget or sleep to equalize elapsed time.
10. Identity/debugger/gate state changes after explicit thaw, or release fails: end owned child. Never release a refused control.
11. Child exits early: retain actual raw exit and phase; do not replace it with another termination code. Cleanup failure preserves original reason and keeps kill-job lifetime fail-closed.
12. Parent dies after assignment: parent-only last-close kills child. Before assignment the never-resumed orphan boundary remains explicit.
13. Control receipt can enroll500k monitoring: fail contract review. Its method/suffix/capacity/committedfalse must make it ineligible.
14. Optional observation follows a changed relative target, mistakes encrypted gate-phase bytes for reference plaintext, reads arbitrary stack words as frames, or claims an exact running-thread predicate: fail evidence review.
15. Postrelease polling or receipt persistence stalls startup: no second freeze/suspension or gate hold is allowed. Polls are sequential external reads and remain outside the absolute gate transaction.
16. Actual repeat has a different game/helper/gate, Steam context, SafeMode choice, PSS/debugger attachment, or unrelated protected-file baseline: mark causal comparison invalid instead of inferring a cause.
