Quiet submission boundary prototype

The factories return Windows SDK COM interfaces backed by an owned sink reference.
WrapRenderClient exposes only IUnknown and IAudioRenderClient.
Each ReleaseBuffer preserves the caller flags and adds AUDCLNT_BUFFERFLAGS_SILENT.
The underlying SDK interface still validates packet order, sizes, and flags.

WrapSoundBuffer exposes only IUnknown, IDirectSoundBuffer, and IDirectSoundBuffer8.
The factory accepts stopped secondary buffers with PCM8, PCM16, or float32 formats.
It also accepts matching WAVEFORMATEXTENSIBLE forms with the full sample width.
The factory rejects primary buffers, effects, 3D controls, notifications, and unsupported capability flags.
The stock voice buffer flags 0x80E8 fit the supported capability set.

Before wrapping, surrender every raw sink alias and finish all raw locks.
Do not start playback until the factory succeeds.
The factory clears the complete output ring before it returns the interface.
PCM8 uses 0x80 bytes. PCM16 and float32 use zero bytes.
Lock returns separate scratch memory with the underlying region sizes.
Unlock submits only format-correct silence to the underlying regions.
Caller writes cannot change the playing output ring.
Keep one Lock/Unlock pair at a time and use the exact returned pointers and sizes.
Do not use a returned write pointer after Unlock.

Restore clears the restored ring before a new Play call can succeed.
If clearing fails, Play returns that failure until a successful restoration clears the ring.
If an underlying Unlock fails, the caller can retry that Unlock with its original regions.
A failed internal clear Unlock leaves the object closed to playback. Recreate that buffer.
Teardown tries to finish a pending lock with silence, then releases the owned sink.
An underlying teardown Unlock failure remains an underlying driver failure.

These interfaces do not create devices or change endpoint, session, or system volume.
The prototype has no activation interception, injection, game loader, or installation path.
It does not cover other COM interfaces, duplicated raw buffers, or other audio APIs.
It does not establish BO3-wide output coverage or startup silence.
The native fixture uses memory sinks and cannot establish real driver compatibility.

Run the focused native fixture from the repository root:
& source/tests/quiet/Test-QuietBoundary.ps1 -OutputDirectory <private-output-directory> -Baseline
& source/tests/quiet/Test-QuietBoundary.ps1 -OutputDirectory <private-output-directory>
The first command requires the expected unprotected failures.
The second command requires all protected scenarios to pass.
Each command writes a JSON report and an executable in the supplied output directory.
Use an output directory outside the repository.
The harness rejects the repository root and its subdirectories before it creates output or finds the compiler.
