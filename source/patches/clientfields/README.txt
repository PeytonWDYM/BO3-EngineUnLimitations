PENDING CLIENTFIELD CALLBACK QUEUE

The default Windows recipe uses two banks of 8,192 pending callback records.
Each record keeps its native 32-byte layout. Both counts follow both banks.
Complete backing size: 524,296 bytes. Stock backing size: 131,080 bytes.

pending_inventory.json pins seven complete native owner functions and seventeen instruction edits.
Generate-PendingProfile.py checks the normalized inventory hash before generating the C++ manifest.
No new executable or capture can enter this profile through its generator.

PendingProfile admits only the original code, zero VM backing, empty callback counts,
and an unpublished pointer or the original static pointer.
PendingStorage allocates complete zeroed RW storage within reach of both native LEAs.
BuildPendingPlan updates both LEAs, all producer/consumer offsets, three complete clears,
two overflow comparisons, bank shifts, and the published pointer in eighteen edits.

FixedPlan includes this storage in its resource closure.
The early checksum coordinator retains that closure alongside its checksum arena.
Both resources stay owned through publication and rollback. Commit retains them before thaw.

Test-PendingCallbacks.py executes the captured producers and full native dispatch loops.
TLS, script callback endpoints, diagnostics, error, and memset endpoints are authored.
It checks both banks, indices 2047/2048/8191, complete clears, and incomplete-recipe failures.
Test-PendingNative.ps1 uses real Windows allocation and publication APIs over owned inert memory.
It checks code/data admission, complete allocation, all eighteen edits, rollback, and commit ownership.
Audit-PendingInventory.py reproduces the observed inventory and private span file from the exact capture.
Keep captures, span files, executable copies, and test results outside Git.

These tests do not execute BO3 or matching peers.
This queue does not raise registered clientfield capacity, packed word budgets, counters,
entity IDs, reliable command rings, or actor limits. Those require separate coordinated changes.
